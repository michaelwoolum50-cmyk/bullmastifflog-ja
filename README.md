# BullmastiffLog（ブルマスティフログ）

ブルマスティフ専用の記録アプリです。開発者: michaelwoolum

## 概要

ブルマスティフは、もともと夜の見回りを担ってきた犬種です。落ち着いていて、静かで、家族に忠実。その毎日の記録を、メモ帳にばらばらに残すのではなく、端末の中の一冊にまとめます。

## できること

- 毎日の記録 — 体重、ごはん、通院をその日のうちに残す。動物病院で聞かれたときに、記憶ではなく記録で答えられます
- 血統の記録 — 父犬、母犬、犬舎、世代を一か所に整理する
- トレーニングの記録 — 何がうまくいって、何がうまくいかなかったかを残し、数か月の変化を見る
- 記録は端末の中に置く、プライベートな設計です
