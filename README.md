# BullmastiffLog — ブルマスティフ専用の記録アプリ

ブルマスティフの飼い主のためだけに作られた、フィールドジャーナル。

穏やかで、恐れを知らず、忠実。ブルマスティフは番人の夜警のために生まれた犬です。50kgを超えることもあるこの犬には、記憶まかせではない、きちんとした記録が必要です。

BullmastiffLogは、日々のケア、血統、そしてしつけを、スマートフォンの中の一冊のプライベートな手帳にまとめます。

- 日々のケア記録 — 体重、ごはん、動物病院への通院。予防接種の記録も含めて、獣医さんに聞かれたときに、推測ではなく記録で答えられます。
- 血統の記録 — 父犬、母犬、犬舎（ケネル）、そして世代を、一冊にまっすぐ整理。
- しつけ記録 — セッションごとに、うまくいったこと・いかなかったことを残し、数か月単位で変化を見返せます。
- プライベート設計 — あなたのブルマスティフの手帳は、あなたの端末の中だけにあります。

静かな忠誠心を持つ大型犬にふさわしい一冊を。BullmastiffLog。
